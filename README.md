# Ola EV Sentiment and Recommendation App

This project analyzes customer reviews for Ola scooter models, summarizes sentiment, and recommends models based on the experience areas a user cares about.

## Run the app

From the project folder (`ml`), install the dependencies and launch Streamlit:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The workbook `Ola_Scooter_Customer_Experience_Dataset_60000.xlsx` must remain beside `app.py`. The app reads the `All_Reviews_60000` sheet.

Run the self-contained unit tests from the project folder with:

```powershell
python -m unittest discover -s . -p "test_*.py" -v
```

## Analysis flow

1. The app loads the review dataset, normalizes text fields, and validates required columns.
2. VADER analyzes each `Customer_Opinion_Experience` and assigns a compound score and Positive, Neutral, or Negative label. The Streamlit cache avoids repeating the calculation for unchanged review text.
3. The dashboard compares VADER with Naive Bayes, Logistic Regression, Linear SVM, Random Forest, and Decision Tree predictions on selected held-out reviews. Classifiers are trained once per app session from 80% of the unique rows in `Ola_60000_Labelled.xlsx`; comparisons are limited to the stratified 20% holdout.
4. The recommendation module continues to use VADER sentiment. It filters reviews by daily usage and ownership duration, then ranks scooter models across selected experience areas. Positive reviews score `+1`, neutral reviews `0`, and negative reviews `-1`; selected areas receive equal weight.

## Project files

- `app.py`: Streamlit dashboard and user interface.
- `sentiment_analysis.py`: VADER classification and training for the supervised sentiment classifiers.
- `recommendation.py`: personalized model ranking.
- `preprocessing.py`: import-safe text cleaning and legacy rating-assisted sentiment labeling.
- `train_model.py`: experiments with supervised classifiers on the labeled review workbook; it prints evaluation results and does not create a model artifact used by the app.

## Model validation

The supervised classifiers use labels generated by the project's VADER labeling workflow, so their agreement on the holdout measures reproduction of VADER rather than independently verified sentiment accuracy. The dashboard keeps VADER as the source for its sentiment score and recommendations. For a trustworthy performance claim, create a human-reviewed holdout set and keep its reviews separate from training and tuning.
